## ✨ 3つのコア機能

### 1. リアルタイム文脈認識 (Context Engine)
アクティブなアプリ・開いているドキュメントを2秒ごとに監視し、「今何をしているのか」を理解します。

### 1.5 🤖 オンデバイスAIキーワード抽出 (v1.1新機能)
Apple NaturalLanguage frameworkが、その文脈から重要キーワードを抽出し、「今欲しい検索」を自動サジェスト。**すべてMacの中だけで処理され、外部送信はゼロ**です。

### 2. スマート提案 (Smart Suggestion)
文脈に合わせて関連資料・リファレンス・タスクを提示。「検索する」という一手間を、ゼロにします。

### 3. Focus Guard (into 集中モード)
Xcode・Safari・Pagesなど「集中すべきアプリ」にいる間はConscio自体がバナーを出さず、離れたときに**実データのセッション報告**（どのアプリで何分集中したか）を1件だけ通知します。※macOSの仕様上、他アプリの通知はOSの通知センターが管理するためConscioでは取得できません — このOSの限界を隠さず、記録できる実データだけを報告します。

### 4. デジタル習慣レポート (Habit Report)
集中時間・文脈の切り替え頻度・使用アプリの統計をポジティブに可視化。「叱らない習慣化」がコンセプト。

## 🔒 リリースzipの検証方法 (1コマンド)

ダウンロードしたzipは、リポジトリ同梱のスクリプトで検証できます（ネットワーク不要・展開は一時フォルダで自動掃除）:

```zsh
git clone https://github.com/Andy234-andy/conscio.git
./conscio/Conscio/tools/verify_release.sh Conscio-v1.4.2.zip \
  1ae2b6f94080a5dd83f54ee99f4dd5acac828acfb93d431808f65e2e18691055
# ✅ SHA-256 一致 → ✅ codesign 検証通過 → バンドルID/バージョン表示
```

期待ハッシュ一覧は [SECURITY.md §6.1](Conscio/SECURITY.md) に全バージョン分掲載。
