# 🛡️ 作業の絶対ルール (2026-10-17 21:57 固定)

> ユーザー(Andy234-andy様)から頂いた、本プロジェクト上での不可侵ルール。

## 1. 個人情報の禁則
- **誰の個人情報も出して、保存して、投稿して、送信してはいけない。** (ユーザー自身のものも他者のものも)
- 名前・住所・電話番号・メアド・ID・スクショ内に含まれる個人情報・マシン名など、外部に露出しうる形式にはしない。
- アカウント所有情報 (X/GitHub/Qiita等) に代理ログイン・クレデンシャル取得を試みない。

## 2. お金の禁則
- **課金・登録・支払い・サブスク・有料API起動を勝手に行ってはいけない。** (1円もダメ)
- 予算の発生しうるリンクへの誘導ボタンをアプリ内に設置してはいけない。
- Apple Developer Program ($99) 加入の寸步も勝手に行わない。

## 3. 公開物の確認ルール
- **記事・投稿・README・Release Note など「世に出るもの」は、毎回必ずユーザーにAdd所未確認を見せる。**
- 未確認のまま自動投稿や更新をしない。
- 記事の公開時に **「AIを使用」の表記を必ず入れる**。この言い訳(エクスポーズ)は全公開物に必須。

## 4. 炎上リスクの禁則
- **ユーザーの名誉・被林有害・反感・流的に培のリスクが微あっても起こせる表現 (炎上リスク) は禁勝手。**
- 他社・他サービスを批判・比較で蹴ることはしない。
- 挑発・煽り・過度な断定・嘘・誇大表現をしない。

## 5. ユーザーに被害が及ぶ行為全般の禁則
- スパム・MLM・誘導・騙リンク設置・セuctive マーケティングを設定してはいけない。

## 6. 自主運営 (ループ/夜間タスク) をやる場合の条件
- 本ルールを毎回読み返してから起動する。
- **公開物が絡む作業 (記事投稿/README/Public なrelease note) は、ユーザーに見せてAdd未確認まで**で止める。
- 公開しない「下準備・build・test・analyze・ドキュメント化・内部」ですがOK。
- ソーシャルの自動投稿アカウント操作は常に行わない (ユーザー自身の手でのみ)。
