## Text (本体)

```
Hi HN! I built a free, tiny (1.5 MB) macOS menu bar app called Conscio.

It watches your frontmost app and document (Accessibility API + NSWorkspace, every 2s), then surfaces context-relevant files, docs and tasks in a popover — the "where was that file?" problem. While you're in a focus app (Xcode, Safari, Pages...), it silently holds notifications and gives you a digest when you surface.

Design philosophy: the problem isn't too much information, it's broken context — so no accounts, no cloud, no telemetry. Everything runs on-device. Built with Swift/SwiftUI; notably it's a hand-assembled .app bundle around an SPM executable (no .xcodeproj needed).

Known limitations: suggestions are rule-based for now (on-device NLP/LLM is on the roadmap), and macOS sandbox makes precise notification attribution hard, so suppression is all-or-nothing while focused.

Site: https://andy234-andy.github.io/conscio/
Source + releases (MIT): https://github.com/Andy234-andy/conscio

Feedback welcome — especially on the suggestion logic and how it should behave with browser tabs.
```
