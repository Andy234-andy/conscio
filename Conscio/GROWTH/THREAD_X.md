## 3/7 (Solution Show)
```
だから作りました。Conscio 🧠

メニューバーに常駐し、
「今この画面で何をしているか」を毎秒読んだい、

必要なファイル・資料・タスクを
勝手に差し出すアプリです。
```

## 4/7 (Focus 機能)
```
しかも集中モードつき。

Xcode や Pages で作業中は通知が全部シャット。
離れたその瞬間に「これだけ気にしておくと良し」
だけのサマリーが届きます。
```

## 5/7 (Philosophy)
```
「情報は選ばせるものじゃない。
選ばれるべき情報だけが、そこにあればいい。」

地図上の toolbar や menu を考慮しています。
```

## 6/7 (Trust)
```
どういうことが素晴らしいか？
- 온デバイス動作 (情報は外に出ない)
- 1.5MB で超軽量
- オープンソース (MIT)
- アカウント不要、課金なし
```
