## AlternativeTo (最重要)
- URL: https://alternativeto.net/suggest/ → "Add Application"
- Name: Conscio
- Category: **Productivity**
- Platforms: macOS
- License: **Free / Open Source**
- Tag: open-source, true/MIT, personalization
- **"Alternative to" 提案** : Alfred, Raycast, Hookmark, Papers
- Description (copy):
```
Conscio is a context-aware menu bar companion for macOS. It reads which app and document you're in, surfaces relevant files/docs/tasks automatically, and silences notifications during focus sessions with a digest on exit. Fully on-device, no accounts, free and open source (MIT).
```
