# Macが急に熱くなったら、容疑者は「CPU窃盗犯」 — 隠れて9時間掘っていた話

2026-10-20 / *本記事はAIアシストで執筆し、人間が内容を確認しています*

---

Mac fan controlを常時入れている私が、ふと「やけに熱い」と思った日があった。
ファンはまだ回っている。だから平気 —— そう思って数時間過ごしていたら、
ターミナルで開いたプロセス一覧に、知らない名前がいた。

## 犯人の履歴書

```
xmrig  /  稼働 9時間25分  /  CPU 417%（6スレッド全開け）
-p pool.hashvault.sh ── Moneroのプール
```

**Monero（仮想通貨）を、他人のウォレット宛に、私のMacで掘っていた。**
1円たりとも私の利益にはならない。奪われたのはCPUと電気代だけ。
そして「熱」は、その犯行の痕跡でもあった。

## 位置について、そして「持続化」

プロセスを kill しても故事は終わらない —— にわか管理者でも知っている。
調べると、ユーザーの LaunchAgents に身に覚えのない2つのファイルがあった。

```
~/Library/LaunchAgents/com.cdatvidywlvigaoc.plist   ← ランダム文字列
~/Library/LaunchAgents/com.uhrgazvowchbnxvo.plist   ← これも
```

中身（Base64を復号して読んだだけ・実行はしていない）は、**AppleScriptが
URLを1文字ずつ組み立てて取得**する、静的スキャン回避の作りだった。
復号した断片に `{"jsonrpc":"2.0","method":"eth_call",...}` が見えた ——
つまりおそらく、**ブロックチェーン上のスマートコントラクトを「設定取得サーバー」代わりに使う**作戦。

設置日を見ると**2ヶ月前**から。13日間再起動なしで稼働していたこのMacでは、
毎日のログインごとにこのエージェントが静かに生きていた。

## 排除の記録（全部で4分）

1. プロセス kill → 負荷が 21.5 から 2.63 まで戻った
2. LaunchAgent 2件を launchctl から退去 → リストから消えることを確認
3. plist を隔離フォルダへ、kit資材は tar で証拠保全してから /tmp から除去
4. その後、AIのループに「**xmrig / 不審LaunchAgent を毎回自動検査**」と
   「発見したら即 kill」「負荷が高ければ重い作業を禁止」をルール化した

## 学んだこと（費やした額に見合う分だけ）

- 「ファンが回っている」は「平気」ではない。**熱は、CPU窃盗の請求書**である
- ランダム文字列の LaunchAgent は、見つけた時点で容疑者。中身は読む、実行はしない
- 誰かの利益にはなっても、**私のMacは私の資産**。素通りさせる損失はゼロに寄せる
- 学びを資産化する最良の方法は、**注意力に依存せず規則に書く**こと。私はAIに
  「毎回検査せよ」と書き込んだ。忘れない設定は、人間の記憶より強い
