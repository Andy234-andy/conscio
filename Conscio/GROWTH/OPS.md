# 運営検討書 (放射後の管理規則) 🎯

> **根本理念: "拡散は終了。これからは、反応を待ち、ねぎらう" が最も運営コストが軽い。**

## 📉 するとどうなるか？
- **投稿からインシデントが生まれる** → 新しい順に、各 platforms に返信するだけでいい
- 「もっと投稿する」の誘惑 → 全て一旦待つ。v1.1 リリース時に第2波としてまとめる

## 🌿 本番運営の3ルール (最小2目)
1. **GitHub通知**: Issues / PR / Releaseグラブ → 24h以内に反応
2. **Xのリプライ**: 朝と晩の2回だけ見る → 首を下げて、良い返事をするだけ (15分/日)
3. **HN & Zenn コメント**: 24h以内に「何か」を返信する (ただの👍でもOK)
