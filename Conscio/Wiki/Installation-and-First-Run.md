# インストールと初回起動 (Installation and First Run)

## 1. ZIPをダウンロード

- [Releases](https://github.com/Andy234-andy/conscio/releases/latest) → `Conscio-macOS-arm64-v*.*.*.zip`
- 対応： **macOS 13+ / Apple Silicon (M1〜)のみ**（Intel対応は未定）

## 2. 展開と配置

1. ZIPをダブルクリック → `Conscio.app` ができる
2. `Conscio.app` を **アプリケーションフォルダ** へドラッグ

## 3. 初回起動（未署名のため2手順）

ConscioはApple開発者IDでの署名（年$99/年をRULESで禁止しているため）を使わない**アドホック署名**です。初回だけ以下が必要です:

1. アプリを **右クリック →「開く」**
2. 「このまま開く」を選択

（通常：FinderダブルクリックではGatekeeperにブロックされることがあります）

## 4. 必要な許可（2種類）

| 許可 | いつ出る | 目的 |
|------|---------|------|
| **アクセシビリティ** | 初回起動で自動プロンプト | 最前面アプリ・ドキュメント・ウィンドウタイトルの検知（Conscioの心臓部） |
| **Safari/Chromeの制御** | Safari/Chrome を最前面にした最初の瞬間 | 文脈からURLを取り込むため（進化#4） |

システム設定 → プライバシーとセキュリティ →「アクセシビリティ」で `Conscio.app` をONに。

## 5. 確認ポイント

- メニューバー右上に **🧠アイコン** が表示されればOK
- アイコンが**紫色**なら集中モードで通知抑制中（進化#3）

## 終了のやり方

🧠アイコンをクリック → 右上の **⚡(電源アイコン)**。Ctrl/Cmd+Qではなく、ポップオーバーから終了します（メニューバー常駐アプリの慣習）。
