# 使い方 (Usage)

> 最終更新: v1.3.0 (2026-10-18) — 進化#8〜#17を反映

## メニューバーの 🧠 をクリック

### グループ① 今日の集中（ビッグ数字）

- 本日の集中時間が**紫色のビッグ数字**で表示されます（値が変わると数字がロール）
- **カード全体をクリック → 習慣レポートが開きます**（進化#16）

### グループ② 現在の文脈

| 表示 | 意味 |
|------|------|
| **アイコン＋アプリ** | いま最前面のアプリ名と**実アイコン**（自動・2秒ごと／進化#15） |
| **ドキュメント** | 開いているファイルやシート名（対応アプリのみ） |
| **URL** | Safari/Chrome最前面タブのURL（クリックで選択可） |

### グループ③ 提案されたアクティビティ（本物だけ）

Conscioの提案は**実在するものだけ**に絞られています（進化#17でデモ表示は全面撤去）:

- 🔄 **「『〇〇』に戻る」** — クリックすると**実際にそのアプリへ切り替わります**（未起動なら自動起動・進化#12）
- 🔎 **「『キーワード』を検索」** — オンデバイスAI(NLTagger)が文脈から選んだキーワードでDuckDuckGoを開く（あなたがクリックした時だけ外部アクセス）

### グループ④ 右上の3ボタン

| ボタン | 機能 |
|--------|------|
| 📊 | **デジタル習慣レポート**を表示 |
| ⚙ | **設定ウィンドウ**を開く（進化#11） |
| ⚡ | **Conscioを終了** |

## デジタル習慣レポート

- **今日の集中 / 直近7日の合計**： 週合計は1日平均分付き（進化#13）
- **集中達成スコア (0-100)**： **目標60分/日の達成率の実データ計算**（進化#10）。達成率で色が変化（≥70緑/30-69橙/<30赤）。「昨日は◯◯分」との比較付き
- **直近7日の集中チャート**： Swift Chartsの棒グラフ
- **文脈切り替え回数** と **最も活用したアプリ** ランキング
- データは再起動しても消えません（保存先はFAQ参照）

## 設定ウィンドウ（進化#11）

- **統計リセット**: 確認ダイアログ付きで全習慣データを削除（JSONファイルごと）
- **データ保存フォルダをFinderで開く**: 保存場所はたった1ファイル
- **パーミッション管理**: システム設定のアクセシビリティ画面を直接開く

## 集中モード（Focus Guard）

- 集中アプリを最前面にしている間、Conscio自体はバナーを出しません
- 解除時に**実データのセッション報告**を1件だけ通知（「Xcode での集中セッション: 42分」・進化#22）
- ※macOSの仕様上、他アプリの通知はOS管理のためConscioでは取得不可 — OSの限界は隠さず、実データだけを報告します
- 集中中はメニューバーの🧠が**紫色**に変化 → 「守ってる」が見える

## 言語

- macOSのシステム言語に従います（日本語環境=日本語UI／英語環境=英語UI）
- 通知文面・時間表示・チャートラベルまで完全対応（進化#17）
