# 使い方 (Usage)

## メニューバーの 🧠 をクリック

### グループ① 現在の文脈
| 表示 | 意味 |
|------|------|
| **アプリ** | いま最前面のアプリ名（自動・2秒ごと） |
| **ドキュメント** | 開いているファイルやシート名（対応アプリのみ） |
| **URL** | Safari/Chrome最前面タブのURL（進化#4、クリックで選択可） |

### グループ② 提案されたアクティビティ
Conscioが文脈から作った提案：

- 📂 **最近の関連アプリ**に戻る提案
- 🔎 **AI検索サジェスト** — オンデバイスAI(NLTagger)が文脈の重要語を抽出し、「いま欲しい検索」をDuckDuckGoで開く（あなたがクリックした場合のみ外部アクセスします）

### グループ③ 右上の2ボタン
| ボタン | 機能 |
|--------|------|
| 📊 (chart) | **デジタル習慣レポート**を表示 |
| ⚡ (電源) | **Conscioを終了** |

## デジタル習慣レポート

- **総ディープワーク時間**： 集中アプリ(Xcode/Safari/Pages/TextEdit/Code)にいた時間の累積
- **直近7日の集中チャート**： Swift Chartsの棒グラフ（進化#5）
- **文脈切り替え回数**： 多い=散漫、少ない=安定の目安
- **最も活用したアプリ**: 利用秒数ランキング
- データは再起動しても消えません（保存先は下のFAQ参照）

## 集中モード（通知抑制）

- 集中アプリを最前面にしている間、通知を**静かにまとめて後回し**
- 解除時に「◯件抑制されました」と1件だけ通知
- 抑制中はメニューバーの🧠が**紫色**变化 → 「守ってる」が見える

## 言語

- macOSのシステム言語設定に従います（日本語環境=日本語UI/英語環境=英語UI）
- 今後対応言語を増やせます（String Catalogへの移行は進化バックログで管理）
